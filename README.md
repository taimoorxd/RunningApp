📱 Offline Step Counter App

A simple and efficient mobile application that counts your daily steps without requiring an internet connection. This app works completely offline and helps you track your physical activity anytime, anywhere.

🚀 Features
✅ Works 100% offline (no internet required)
👣 Accurate step counting using device sensors
🔋 Battery efficient
📊 Daily step tracking
🔒 No data collection — privacy friendly
📱 Simple and user-friendly interface

🛠️ Tech Stack
Language: HTML CSS JAVASCRIPT
Sensors: Accelerometer / Step Detector
Platform: ANDRIOD/IOS

▶️ How It Works
App device ke built-in sensors use karti hai (accelerometer / step detector)
Steps automatically detect hote hain jab user walk karta hai
Data locally store hota hai (no cloud, no internet)
